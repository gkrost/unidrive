## Rules for every item

1. **Check first whether it is already done.** In the 2026-10-16 wave two of six items turned out to be merged already. Before any code: `gh issue view <n> --comments`, `gh pr list --state all --search "<n>"`, `git log origin/main -S<symbol>`. If it is done, stop and report with evidence, no PR.
2. One item = one branch from a clean `origin/main` worktree (never the shared checkout) = one DRAFT PR; the owner merges. At most three agents at a time.
3. Run only the touched tests (`cd core && ./gradlew :module:test --tests '...'`), never a full `check` (CI does). Red-check every new test. No live accounts, no deploy.
4. Reuse before building (see memory note "check existing before building"): find the existing mechanism, extend it.
5. End commits with the `Co-Authored-By` line and PR bodies with the generated-with line, as the session reminder says.
